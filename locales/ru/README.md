# AI Code Orchestrator

> Ваша команда разработчиков на базе ИИ — прямо в редакторе.

AI Code Orchestrator — это расширение VS Code и CLI для планирования, реализации, проверки и объяснения программного обеспечения с помощью настраиваемых ИИ-агентов. Он объединяет чат, действия с кодом, работу в терминале, пользовательские роли, интеграции MCP и мультиагентную оркестрацию в одном рабочем пространстве.

## Возможности

- Создание и изменение кода по требованиям на естественном языке
- Проектирование архитектуры и разбиение работы на согласованные задачи
- Оркестрация работы в виде DAG с учетом зависимостей, параллельными исполнителями, этапами review, бюджетами и контролируемой интеграцией
- **Оптимизация контекста** — интеллектуальное управление контекстом снижает расход токенов и затраты, сохраняя эффективность
- Проверка изменений, диагностика сбоев и улучшение существующего кода
- Работа с файлами, терминалами, изображениями и внешними инструментами MCP
- Настройка провайдеров, включая Vercel AI Gateway и Unbound, моделей, разрешений и пользовательских ролей
- Назначение моделей отдельным ролям с автоматическим наследованием основной модели, если переопределение не задано
- Продолжение задач из редактора или командной строки

## Роли

AI Code Orchestrator адаптируется к текущей задаче:

- **Code** — реализация изменений и работа с файлами проекта
- **Architect** — проектирование систем, спецификаций и миграций
- **Ask** — ответы на вопросы и объяснение кода
- **Debug** — поиск первопричин и проверка исправлений
- **Reviewer** — проверка изменений, выявление проблем и обеспечение качества
- **Orchestrator** — координация графов задач с зависимостями и параллельных агентов; роль используется по умолчанию
- **Translate** — перевод и управление файлами локализации
- **Custom** — создание специализированных рабочих процессов для команды

Каждая роль может использовать собственную конфигурацию модели. Если модель для роли не назначена, она наследует основную модель, что позволяет удобно балансировать возможности, скорость и стоимость рабочего процесса.

## Установка

Установите расширение **AI Code Orchestrator** из VS Code Marketplace или соберите VSIX локально:

```bash
pnpm install
pnpm vsix
```

Во время разработки CLI доступен из монорепозитория:

```bash
pnpm --filter @ai-code-orchestrator/cli dev
```

Область пакетов и устаревшие идентификаторы команд сохранены для совместимости с существующими интеграциями.

## Происхождение

AI Code Orchestrator создан на основе [Roo Code](https://github.com/RooCodeInc/Roo-Code). В реализации сохранены некоторые совместимые API и идентификаторы, чтобы существующие интеграции продолжали работать.
