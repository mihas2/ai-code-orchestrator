# AI Code Orchestrator 1.3.5 Release Notes

## Changed

- **Mode changes go through subtasks only.** The `switch_mode` tool has been removed. Models often switched modes instead of delegating and then never switched back, which broke orchestration. Work that needs another mode is now always delegated with [`new_task`](/advanced-usage/available-tools/new-task), and the parent keeps its own mode. Follow-up question suggestions no longer carry a mode. The **Mode** auto-approve permission was removed because there is nothing left to approve.
- **Parallel tool calls are a per-profile setting for every provider.** **Enable parallel tool calls** is now in each profile's Advanced settings and applies to all providers whose APIs support it. It is off by default. See [Parallel Tool Calls](/providers/openai-compatible#parallel-tool-calls).

## Fixed

- **Roles settings are independent of the chat and of Providers.** Selecting a role in Settings → Roles no longer follows or changes the chat's mode. Creating or importing a role no longer switches the chat. Each role's model list is loaded from the profile assigned to that role, not from the profile selected in Settings → Providers. See [Linking Profiles to Roles](/features/api-configuration-profiles#linking-profiles-to-roles).
- **Stop works on the first click**, including while a tool or command is running or between API requests. The command the task was waiting on is stopped too.
- **The Condense Context button no longer stays stuck.** A failed manual condense is reported as an error, and the button becomes available again.
- **"Go to subtask" opens the right child task**, including in existing task history.
- **Unusable tool calls are reported** in the chat instead of showing empty tool blocks. The model is told about the error and can retry.
