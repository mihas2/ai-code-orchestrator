# AI Code Orchestrator 3.25.17 Release Notes (2025-08-18)

This release fixes issues with LM Studio model management and terminal reuse logic.

## Bug Fixes

* **LM Studio Models**: Fixed duplicate model entries by implementing case-insensitive deduplication, ensuring models appear only once in the provider configuration ([#7185](https://github.com/AIOrchestrator/ai-code-orchestrator/pull/7185))
* **Terminal Reuse**: Fixed terminal reuse logic to properly handle terminal lifecycle management ([#7157](https://github.com/AIOrchestrator/ai-code-orchestrator/pull/7157))
