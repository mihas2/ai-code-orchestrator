# AI Code Orchestrator 3.40.1 Release Notes (2026-01-14)

* Fixes an issue where switching modes (e.g., from Code to Architect) while using Gemini would cause API errors due to tool permission conflicts in the conversation history. ([#10708](https://github.com/AIOrchestrator/ai-code-orchestrator/pull/10708))
