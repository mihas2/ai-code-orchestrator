# AI Code Orchestrator 1.3.0 Release Notes (2026-09-09)

## Changed

- **Improved orchestrator behavior as team-lead**: orchestrator now acts as a persistent team lead, maintaining role context across delegated subtasks and reliably recovering parent role after each delegation
- Unified role prompts and metadata across all orchestration modes, ensuring consistent system prompt generation and mode-to-role mapping for delegated agents

## Fixed

- Reliably restores parent role after delegated task completion, preventing role leakage across subtask boundaries
