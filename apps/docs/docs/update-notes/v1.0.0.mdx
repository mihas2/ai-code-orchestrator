# AI Code Orchestrator 1.0.0 Release Notes

## About the Project

**AI Code Orchestrator** is a fork of the original Roo-Cline project, extended with support for:

- **Multi-agent orchestration** with task decomposition and delegation
- **Role-based model assignment** for specialized agents
- Multiple AI providers and models
- Enhanced development automation capabilities

## Initial Release

The first version includes core AI assistant functionality for development:

- VS Code integration
- Support for multiple AI providers (Anthropic, OpenAI, OpenRouter, etc.)
- Basic code manipulation tools
- Codebase indexing
- MCP (Model Context Protocol) support
- Multilingual interface
