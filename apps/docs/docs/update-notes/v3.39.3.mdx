# AI Code Orchestrator 3.39.3 Release Notes (2026-01-10)

This release renames AI Code Orchestrator Cloud Provider to AI Code Orchestrator Router and improves CLI and internal organization.

<img src="/img/v3.39.3/v3.39.3.png" alt="AI Code Orchestrator v3.39.3 Release" width="600" />

## AI Code Orchestrator Router rename

AI Code Orchestrator now shows **AI Code Orchestrator Router** anywhere the extension previously referred to the **AI Code Orchestrator Cloud Provider**. The new name is meant to make the intent clearer: AI Code Orchestrator Router is a router-style provider (similar in idea to other router/aggregator services), but with a **curated set of models we’ve tested with AI Code Orchestrator**. ([#10560](https://github.com/AIOrchestrator/ai-code-orchestrator/pull/10560)).

## QOL Improvements

* **AI Code Orchestrator Router naming consistency**: Updates the AI Code Orchestrator Router service name and link so the UI points at the correct destination ([#10607](https://github.com/AIOrchestrator/ai-code-orchestrator/pull/10607))
* **AI Code Orchestrator Router naming consistency**: Updates router naming in shared types so labels stay consistent across the UI ([#10605](https://github.com/AIOrchestrator/ai-code-orchestrator/pull/10605))
* **ExtensionHost organization**: Improves internal organization around mode changes and related events to help keep behavior consistent ([#10600](https://github.com/AIOrchestrator/ai-code-orchestrator/pull/10600))
* **CLI release testing**: Adds options to build and install the CLI release locally for testing ([#10597](https://github.com/AIOrchestrator/ai-code-orchestrator/pull/10597))
* **CLI organization**: Reorganizes the CLI file structure to make future changes easier to maintain ([#10599](https://github.com/AIOrchestrator/ai-code-orchestrator/pull/10599))

## Misc Improvements

* **CLI TUI**: Adds an interactive terminal UI mode to the AI Code Orchestrator CLI ([#10480](https://github.com/AIOrchestrator/ai-code-orchestrator/pull/10480))
