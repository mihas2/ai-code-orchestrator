# AI Code Orchestrator 3.25.18 Release Notes (2025-08-19)

Update to AI Code Orchestrator 3.25.18 to access Sonic — a stealth model from a major AI provider — with a massive 262,144‑token context and FREE 72‑hour access. This release also includes provider enhancements and reliability fixes.

## Sonic (Stealth Model)

Sonic is now available in AI Code Orchestrator ([#7207](https://github.com/AIOrchestrator/ai-code-orchestrator/pull/7207)) ([#7212](https://github.com/AIOrchestrator/ai-code-orchestrator/pull/7212)) ([#7218](https://github.com/AIOrchestrator/ai-code-orchestrator/pull/7218))  — a stealth model from a major AI provider designed for long‑range, context‑rich work:

- 262,144‑token context lets you work across very large codebases, logs, and transcripts in one session.
- FREE for 72 hours so you can try Sonic with real tasks.

> Important: Sonic is delivered via AI Code Orchestrator Cloud. To get this model to work, you must connect your IDE to AI Code Orchestrator Cloud. See Connect to AI Code Orchestrator Cloud.

**Prerequisites**
- AI Code Orchestrator v3.25.18 or later
- Connected to AI Code Orchestrator Cloud account — see Connect to AI Code Orchestrator Cloud

**How to enable Sonic**
1. Open Settings → Providers and set Provider to **AI Code Orchestrator Router**.
2. In the model selector, choose **Sonic**.

> 📚 Documentation: See Connect to AI Code Orchestrator Cloud and AI Code Orchestrator Router.
