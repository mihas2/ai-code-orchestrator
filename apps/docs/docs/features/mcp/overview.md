# Model Context Protocol (MCP)

The Model Context Protocol (MCP) is a standard for extending AI Code Orchestrator's capabilities by connecting to external tools and services. MCP servers provide additional tools and resources that help AI Code Orchestrator accomplish tasks beyond its built-in capabilities, such as accessing databases, custom APIs, and specialized functionality.
