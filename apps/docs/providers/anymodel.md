# Using AnyModel With AI Code Orchestrator

AI Code Orchestrator supports accessing models through the [AnyModel](https://anymodel.org/?ref=ZKS6EEZ) platform. AnyModel provides access to multiple AI models from various providers at competitive prices.

**Website:** [https://anymodel.org/?ref=ZKS6EEZ](https://anymodel.org/?ref=ZKS6EEZ)

---

## Getting an API Key

1.  **Sign Up:** Go to the [AnyModel website](https://anymodel.org/?ref=ZKS6EEZ) and create an account.
2.  **Get Free Tokens:** New users receive 5 million tokens upon registration.
3.  **Get API Key:** Navigate to your account dashboard to find or generate your API key.
4.  **Copy the Key:** Copy the API key for use in AI Code Orchestrator.

---

## Available Models

AI Code Orchestrator automatically fetches all available models from AnyModel's API.

For the complete, up-to-date model list with pricing and capabilities, see AnyModel's models page.

---

## Configuration in AI Code Orchestrator

1.  **Open AI Code Orchestrator Settings:** Click the gear icon (⚙️) in the AI Code Orchestrator panel.
2.  **Select Provider:** Choose "AnyModel" from the "API Provider" dropdown.
3.  **Enter API Key:** Paste your AnyModel API key into the "AnyModel API Key" field.
4.  **Select Model:** Choose your desired model from the "Model" dropdown.

---

## Tips and Notes

- **Free Tokens:** New users get 5 million tokens to start exploring different models at no cost.
- **Competitive Pricing:** AnyModel offers access to multiple AI models at attractive price points.
- **Model Selection:** Experiment with different models to find the best fit for your coding tasks and budget.
